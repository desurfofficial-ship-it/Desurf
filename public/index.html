Desurf Behavioral Contract Specification

AI outputs surf on the surface. Desurf checks what is underneath — the behavioral contract. Traditional software tests expect identical output; LLMs produce variations. Desurf tests explicit behavioral assertions across repeated executions.

Supported Assertions

required

Asserts output contains a substring.

{ "type": "required", "value": "billing" }
forbidden

Asserts output NEVER contains substring (e.g. AI leaks).

{ "type": "forbidden", "value": "I am an AI" }
regex

Asserts output matches regular expression pattern.

{ "type": "regex", "pattern": "\"category\"\\s*:\\s*\"billing\"" }
json_schema

Asserts output is valid JSON matching structural schema.

{ "type": "json_schema", "schema": { "required": ["category"] } }

Exit Code Contract (CI Integration)

0 PASS — All assertions pass across all test cases and repeated executions
1 REGRESSION / FLAKY — Quality gate failure (assertion violations or nondeterminism)
2 ERROR — Tool, configuration, missing file, or provider timeout failure
